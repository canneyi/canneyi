# canneyi-skills

Claude Code plugin bundling two skills:

- **karpathy-guidelines** — Behavioral guidelines to reduce common LLM coding mistakes (think before coding, simplicity first, surgical changes, goal-driven execution). From [multica-ai/andrej-karpathy-skills](https://github.com/multica-ai/andrej-karpathy-skills) (MIT).
- **tufte-viz** — Ideate and critique data visualizations using Edward Tufte's principles. From [aparente's gist](https://gist.github.com/aparente/e48c353755958621b3c0004593105a90).

## Install

Inside Claude Code:

```
/plugin install https://github.com/canneyi/canneyi --branch claude-skills
```
